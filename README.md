# Introduction

## Introduction

### 1. In how many steps do all the DSA problems are solved?

**A.** All the DSA problems are solved in a two steps process:

1. Approach the problem in a certain way and developing a solution.
2. Straight coding.

## Which Language?

### 2. In which language DSA needs to be done?

**A.** Data Structure and Algorithm (DSA) is language agnostic that means DSA doesn't care in which language I'm solving the problem in. So, I can do DSA in any language because the approach to solve the problem remains the same no matter what language it is.
