# Count Digit

27. What is the basic logic to find the number of digits in the number, let say n = 259 and n = 45786 algorithmically?

A.

```text
n = 259

259 ÷ 10
25 ÷ 10
2 ÷ 10
0

3
```

```text
n = 45786

45786 ÷ 10
4578 ÷ 10
457 ÷ 10
45 ÷ 10
4 ÷ 10
0

5
```

So, write a loop in such a way where I have to keep dividing the number by 10 and I have to run the loop unless 0 is left.
